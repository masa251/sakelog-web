制定日 2026年9月10日 ／ 最終更新日 2026年10月11日

01適用範囲

本プライバシーポリシー(以下「本ポリシー」)は、日本酒の記録アプリ「SakeLog」(Android版およびWeb版。以下「本アプリ」)における利用者情報の取り扱いについて定めるものです。

02扱う情報

本アプリが扱うのは、利用者ご自身が入力・撮影・選択した次の情報です。会員登録・ログインの機能はなく、氏名・メールアドレス・電話番号・位置情報などの入力や取得は行いません。

  • カメラで撮影した写真、またはギャラリー(Web版ではファイル選択)から選んだ写真(最大6枚)
  • 銘柄名、酒蔵名、産地(都道府県)、使用米、精米歩合、アルコール度数、日本酒度、酸度
  • 甘口・中間・辛口、飲みやすさ、甘み・旨み・酸味・苦み・香りの評価、飲用温度、レア度、参考価格、メモ、飲んだ日、お気に入り
  • (Android版のみ)アプリが予期せず終了したときのエラーの記録(エラーの内容のみで、記録データや写真は含みません)

すべての項目は任意入力です。

03保存場所

記録データと写真は、利用者の端末(Web版ではお使いのブラウザ)の中にだけ保存されます。開発者のサーバーへ送信・同期することはありません。

Android版

  • 記録データは、端末内のアプリ専用データベースに保存されます。
  • 写真は、アプリ専用の保存領域に保存されます。カメラで撮影した写真は、端末のギャラリー(「SakeLog」アルバム)にも保存されます。
  • エラーの記録は、アプリ専用の保存領域に保存され、設定画面から確認・コピーできます。自動で外部へ送信されることはありません。
  • アプリの設定状態(プラン設定など)は、端末内の設定ストレージに保存されます。

Web版

  • 記録データと写真は、お使いのブラウザの保存領域(IndexedDB)に保存されます。別の端末やブラウザとは共有されません。
  • 「バックアップ」機能で書き出したファイルは、利用者が選んだ場所に保存されます。その後の管理は利用者ご自身で行ってください。

04利用目的

  • 記録の一覧表示・検索・振り返り、統計の表示
  • 甘口・中間・辛口や飲用温度から、合いそうな料理を提案すること(提案は端末・ブラウザの中で計算します)
  • ラベル写真の文字を読み取り、銘柄名などの入力を手助けすること
  • (Android版)アプリの不具合の原因を調べること(エラーの記録)

05ラベルの文字読み取りと外部サービス

Android版

文字の読み取りには、Google社が提供する ML Kit(端末内で動作する文字認識)を使用しています。写真と読み取り結果は端末内で処理され、外部へ送信されません。ただし ML Kit は、機能の維持・改善のため、写真や読み取り結果を含まない利用状況・診断情報(端末やアプリの種類、処理の性能など)を Google 社へ送信することがあります。詳しくは Google の ML Kit データ開示ページ をご覧ください。

Web版

文字の読み取りには Tesseract.js を使用しています。読み取りのためのプログラムと文字データは、初回利用時などに配信サービス(jsDelivr)からブラウザへ読み込まれます。写真と読み取り結果はブラウザの中で処理され、外部へ送信されません。

また、Web版は GitHub Pages で配信しており、画面の文字表示に Google Fonts を使用しています。これらのサービスには、ページを表示する際に、通常のWebサイトと同様に IP アドレスやブラウザの情報が送られます。記録データや写真が送られることはありません。

06第三者への提供

記録データや写真を、広告事業者・アクセス解析事業者を含む第三者へ提供することはありません。本アプリは現在、広告やアクセス解析の機能を使用していません。

07Android版で使用する権限

権限利用目的
カメラ日本酒のラベルなどを撮影するため

インターネット接続文字認識(ML Kit)の部品が使用します。記録データや写真の送信には使用しません。

08データの削除

  • 記録は、アプリ内の削除機能からいつでも1件ずつ削除できます(削除前に確認画面が表示されます)。
  • Android版をアンインストールすると、アプリ内に保存された記録・写真・エラーの記録は端末から削除されます。ギャラリーの「SakeLog」アルバムに保存された写真は残るため、必要に応じてギャラリーアプリから削除してください。
  • Web版の記録は、ブラウザの「サイトデータの削除」を行うと削除されます。
  • 開発者のサーバーにはデータの控えがないため、削除したデータは復元できません。

09未成年の方のご利用について

本アプリはお酒の記録を目的としており、20歳未満(またはお住まいの地域の飲酒可能年齢未満)の方の利用を想定していません。

10本ポリシーの変更

機能の追加(広告・アクセス解析・課金など)や法令の変更に伴い、本ポリシーを変更することがあります。利用者情報の取り扱いに関わる重要な変更は、本アプリ内または本ページでお知らせします。
